
# Astra Asteroids

Astra Asteroids adds a set of new asteroids and recipes to the game, for each of the core planets. This mod is primarily intended to work with Astra Explorer (unreleased), but can run on it's own with recipes for everything.  

If you have specific other mods (some form of interplatform item exchange, removing surface restrictions to allow things on platforms, and factorissimo(for allowing greenhouses on platforms)) you can run your entire game in space after you get the techs from the ground. 

Note: This adds more asteroids and increases the difficulty of space routes.

## Features
- Adds a new asteroid for every planet, with that planets key resource/s from it (and usually stone) - with basic and advanced(or alternative?) versions of each. 
- An optional, setting-based crude oil asteroid (on Nauvis), via the new oilstone item.
- Includes recipes with a chance to find living biter/penta eggs from their respective chunks.
- Increases asteroid quantity - approximately 5x medium asteroids, and 8x total chunks (after breaking down bigger asteroids).
- Includes asteroid productivity and reprocessing for each.
- Recipes are unlocked all at once with existing techs (space platform, advanced asteroid processing, asteroid reprocessing)

## Compatability
- All items/recipes/etc added in this mod are given prefixed names that shouldn't overlap with anything else.  This should mean no conflicts, but no inherent compatability either.  
- Asteroid spawn definitions for each base planet and route are changed.
