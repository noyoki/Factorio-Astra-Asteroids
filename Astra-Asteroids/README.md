
# Astra Asteroids

Astra Asteroids adds a new asteroids and recipes to the game. This mod is primarily intended to work with Astra Explorer, but can run on it's own with basic recipes for everything.  

## Features

- Adds a new asteroid for every planet, with that planets key resource from it - with basic and advanced versions of each. 
- Adds an optional, setting-based crude oil asteroid for Nauvis.
